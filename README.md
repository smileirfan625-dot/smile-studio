## 🌐 Live Website & GitHub Pages Setup (Fixing 404 Errors)

If your website showed **404 Not Found** on GitHub, follow these 1-minute steps to enable GitHub Pages:

### Step-by-Step GitHub Pages Activation:
1. Open your repository on GitHub.
2. Click on **Settings** (top right tab of the repository).
3. In the left sidebar, click on **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` (or `master`).
   - **Folder**: Select `/ (root)`.
5. Click **Save**.
6. Within 1–2 minutes, GitHub will publish your site at:
   ```
   https://<your-github-username>.github.io/<repository-name>/
   ```
   The root `index.html` file provides the full interactive website with zero 404 errors!

## 📱 Android App Setup

This project is a complete dual-target platform:
- **Web App**: Hosted via `index.html` on GitHub Pages / browser.
- **Android App**: Native Kotlin + Jetpack Compose + Material Design 3 app inside `/app`.

### Opening in Android Studio:
1. Clone or download this repository.
2. Open **Android Studio** and choose **Open an Existing Project**.
3. Select the root folder of this repository.
4. Let Gradle sync dependencies.
5. Click **Run 'app'** (green play icon) or build an APK via:
   `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`.
